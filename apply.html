A few helpful answers.

Quick guidance for completing this student project application form.

Which job reference should I use?

Use FE101 for Front-End Web Developer or UX102 for UX/UI Designer. Type the reference or choose a suggestion in the Job reference number field. Compare the two roles before choosing.

Can I apply for both roles?

Yes. Submit a separate application for each job reference, so your information is associated with the correct role.

Do I need to attach a CV?

No. The CV / Resume field is optional. In this version it only lets you preview a file selection: your CV is not uploaded or stored, and leaving it empty does not block submission.

What happens when I submit this form?

This is a student project. Your form entries are sent to the university form test service, which displays the submitted name/value pairs. This is not a real job application. Use fictional details when testing; the selected CV is not included.
