ENGINEERING

Reference: FE101

Front-End Web Developer

Build responsive, accessible interfaces for our learning management platform. Help students and educators manage courses, learning resources, assignments and progress through clear, reliable web experiences.

Salary range
AUD $80,000–$100,000 per year, plus superannuation
Reports to
Lead Front-End Developer
Location
Melbourne, Australia · Hybrid
Employment
Full-time

Key responsibilities

  1. Develop and maintain responsive course, assignment and learner dashboard interfaces.
  2. Translate approved designs into semantic HTML, reusable CSS and well-structured front-end code.
  3. Improve keyboard navigation, screen reader support and the accessibility of forms.
  4. Test interfaces across browsers and screen sizes, and resolve usability issues.
  5. Collaborate with designers, educators and back-end developers through code reviews and Git workflows.

Essential requirements

  • Degree or diploma in IT, software development or a related field, or equivalent practical experience.
  • Working knowledge of HTML5, CSS3, JavaScript and responsive web design.
  • Understanding of accessible web development, including labels, headings and keyboard interactions.
  • Experience using Git and a portfolio or project demonstrating front-end development skills.
  • Clear communication, problem-solving skills and an interest in inclusive education.

Preferable requirements

  • Experience with a component-based framework such as React or Vue.
  • Familiarity with learning management systems and educational web applications.
  • Experience with accessibility testing and front-end performance optimisation.

DESIGN & UX

Reference: UX102

UX/UI Designer

Design intuitive learning experiences for students and educators. Turn user research into accessible interfaces that make finding resources, submitting assignments and understanding progress easier for diverse learners.

Salary range
AUD $75,000–$95,000 per year, plus superannuation
Reports to
Product Design Lead
Location
Melbourne, Australia · Hybrid
Employment
Full-time

Key responsibilities

  1. Research learner and educator needs through interviews and usability testing.
  2. Create user flows, wireframes and interactive prototypes for key learning tasks.
  3. Design clear navigation, readable layouts and accessible interaction states.
  4. Maintain a consistent design system and document components for developers.
  5. Refine designs using feedback from users, educators and the product team.

Essential requirements

  • Qualification in interaction design, digital design or a related field, or equivalent practical experience.
  • A portfolio explaining your design process, decisions and response to user feedback.
  • Ability to produce wireframes, prototypes and interface designs using Figma or a similar tool.
  • Understanding of user-centred design, responsive layouts and accessible visual design.
  • Strong collaboration skills and the ability to communicate design ideas clearly.

Preferable requirements

  • Experience designing educational products or learning management systems.
  • Familiarity with HTML and CSS to support collaboration with developers.
  • Experience conducting research with people with diverse access needs.
Apply for this role: UX/UI Designer

Use reference UX102 in your application.
